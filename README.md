# Apex Signal Racing - PWA Prototype v0.2.0

Diff update from v0.1.x. This version keeps the existing structure and applies differential changes.

## Main changes
- Racing-style top screen with ASR logo, signal lights, grid background, and large Race Start button
- Larger centered qualifying start UI
- Neon circular qualifying targets by difficulty
- Race screen changed to small course map + event frame
- New corner tap game: curved lane, Apex frame, moving car, and timing judgement
- 2-second event preview for race events
- Pause menu with Quit Race and Retry Race options
- Events-left HUD and tyre pace warnings
- Result log tabs: Race Impact / Control Log
- CSS-based podium and award animations
- Lightweight Web Audio API BGM and sound effects
- PWA cache name updated to v0.2.0

## How to check first
1. Upload this folder to a static host such as GitHub Pages.
2. Open `index.html` on iPhone Safari.
3. Add to Home Screen and verify PWA launch.
4. Priority: launch, layout, tap response, save/restore.

## Included scope
- Final Prototype Circuit / 80 cells / 12 corners / 2 ABC Zones / 1 pit entry
- 1 Lap and 3 Laps modes
- 22-car race with 21 CPU drivers
- Qualifying visual tap test
- Tyre sets and weather selection
- Simplified Race Control, appeal and evidence cards
- 10 awards
- Local rankings
- Test Mode

## Not included
Online ranking, chat, hp purchases, real weather API, replay, spectator mode, World Final.
